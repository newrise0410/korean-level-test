# 한국어 레벨테스트 (데모)

외국인 유학생이 재학 중 정기적으로 자신의 한국어 수준(1~6급)을 확인하고,
한국어문화원이 학생별 성장 추이를 관리하기 위한 웹 시스템의 시연용 버전입니다.
PC·휴대폰 브라우저에서 모두 동작하며 앱 설치가 필요 없습니다.

## 기능

**학생 화면**
- 이름·학번·국적 입력 → 학습 기간에 따라 시작 급 자동 설정
- 적응형 객관식: 어휘·문법·읽기·듣기 각 1문항씩 4문항 블록으로 출제, 정답률에 따라 급을 올리거나 내림 (최대 24문항, 약 15~20분)
- 판정된 급에 맞춘 쓰기 과제와 말하기 녹음 과제 (OPIc 방식)
- 결과: 급 판정, 급별 능력 기술, 영역별 결과, **추천 교재**, 지난 시험 대비 변화와 성장 그래프
- 재응시 때 직전 시험에 나온 문항은 피해서 출제

**관리자 화면** (`#/admin`, 데모 PIN `1234`)
- 학생 수, 평균 급, 지난 시험 대비 상승 비율, 채점 대기 건수
- 현재 급 분포와 **급별 필요 교재 수량**
- 반 필터, 검색, 학생별 응시 이력과 성장 그래프
- 쓰기 답안 열람, 말하기 녹음 재생, 교사 평가와 최종 급 확정, 메모
- CSV 내보내기 (엑셀에서 바로 열림)
- 설정: 기관명, PIN, 급별 추천 교재명
- '데모 데이터 생성': 가상 학생 24명의 3개 학기 응시 기록

## 실행

```bash
npm install
npm run dev      # http://localhost:5173 (같은 와이파이의 휴대폰에서는 Network 주소로 접속)
npm test         # 판정 엔진 테스트
npm run build    # dist/ 정적 파일 생성 → Netlify·Vercel·GitHub Pages 등에 그대로 올리면 됨
```

## 데모의 한계와 실서비스 전환 시 할 일

| 항목 | 데모 | 실서비스 |
|---|---|---|
| 데이터 저장 | 브라우저 localStorage (기기별로 따로 저장) | 서버 DB. `src/lib/store.ts`만 교체하면 됨 |
| 문항 | 급당 8문항, 총 48문항 샘플 | 교재 집필진이 검수한 문항 은행 (급·영역별 수십 문항 이상). 블록도 더 길게 해서 판정 오차를 줄임 |
| 듣기 음성 | 브라우저 TTS | 성우 녹음이나 고품질 TTS로 만든 mp3 |
| 말하기·쓰기 | 교사 수동 채점 | AI 1차 채점(루브릭 기반 점수와 피드백)을 붙이고 교사가 확정 |
| 로그인 | 학번 입력, 관리자 PIN | 학생 계정, 교사·관리자 권한 분리 |
| 운영 | — | 시험 기간 지정, 반별 응시 링크, 결과 PDF 출력 |

## 구조

```
src/
  data/items.ts      문항 은행, 급별 능력 기술, 쓰기·말하기 과제
  lib/engine.ts      블록 적응형 판정 로직 (+ engine.test.ts)
  lib/store.ts       저장소 (localStorage), 데모 데이터, CSV
  lib/media.ts       듣기 TTS, 말하기 녹음 저장 (IndexedDB)
  pages/             Home(응시 정보) · Test · Result · Admin · Charts
```
